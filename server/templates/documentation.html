API Documentation

SeedFinder é uma API REST que localiza estruturas do Minecraft Bedrock a partir de uma seed e posição do jogador. Tudo em JSON.

Visão geral

Todos os endpoints abaixo são alcançáveis em https://mineseedfinder.vercel.app e retornam JSON. A busca percorre as regiões de geração ao redor do jogador, valida os biomas via cubiomes e ordena os resultados por distância.

Base URL

https://mineseedfinder.vercel.app

Endpoint GET /status

Health check. Indica se a biblioteca nativa foi carregada e a versão.

Resposta 200:

{
  "ok": true,
  "version": "..."
}

Resposta 500:

{
  "status": "error",
  "message": "..."
}

Endpoint GET /scan

Efetua o scan de estruturas perto da posição informada.

Parâmetros da query

ParâmetroTipoDefaultDescrição
seed int (uint64) 0 A seed do mundo.
x float 0 Coordenada X do jogador (em blocos).
z float 0 Coordenada Z do jogador (em blocos).
radius int 100 Raio de busca em chunks. Limitado a 1000.
max int 20 Máximo de resultados. Limitado a 1000.
types string 5 IDs de estruturas separados por vírgula.
Todo parâmetro ausente ou inválido é substituído pelo default. A resposta inclui um array missing_or_invalid listando os parâmetros trocados pelo servidor.

Exemplo de resposta 200:

Erro 400 (parâmetro inválido):

{
  "error": "Invalid parameter: ...",
  "missing_or_invalid": ["seed"]
}

Erro 503 (biblioteca nativa não carregada):

{
  "error": "SeedFinder native library (.so) not loaded on this server.",
  "hint": "Check Vercel build logs for messages starting with [seedfinder].",
  "missing_or_invalid": [],
  "results": []
}

Exemplos de clientes

Escolha a linguagem abaixo para ver como chamar /scan com requests (Python), network.get (Lua, ex.: dentro do Flarial Client) ou o módulo nativo https (Node.js). 

import requests

BASE = "https://mineseedfinder.vercel.app"

def scan(seed, x=0, z=0, radius=100, max_=20, types="5"):
    params = {
        "seed": seed,
        "x": x,
        "z": z,
        "radius": radius,
        "max": max_,
        "types": types,  # comma-separated structure IDs, e.g. "5,8,9"
    }
    r = requests.get(f"{BASE}/scan", params=params, timeout=15)
    r.raise_for_status()
    return r.json()

if __name__ == "__main__":
    data = scan(seed=31415, x=0, z=0, radius=100, max_=50, types="5,8,9")
    for s in data.get("results", []):
        print(f"{s['name']:<14} (x={s['x']}, z={s['z']}) dist={s['distance']}")
-- Drop-in para módulos do Flarial Client. `network` é um global do Flarial.
local BASE = "https://mineseedfinder.vercel.app"

local function scan(seed, x, z, radius, maxResults, types)
    local url = string.format(
        "%s/scan?seed=%d&x=%d&z=%d&radius=%d&max=%d&types=%s",
        BASE, seed, x, z, radius, maxResults, types
    )
    -- seedfinder usa types= para os IDs das estruturas, ex.: "5,8,9"
    local resp = network.get(url)
    if not resp or resp.code ~= 200 then
        print("[seedfinder] HTTP error: " .. tostring(resp and resp.code))
        return nil
    end
    return resp.body  -- string JSON; adapte com sua lib JSON se necessário
end

-- Exemplo: vilas, monumentos e mansões ao redor do spawn na seed 31415
local body = scan(31415, 0, 0, 100, 50, "5,8,9")
print(body or "no response")
// Sem dependências — usa o fetch nativo do Node 18+.
const BASE = "https://mineseedfinder.vercel.app";

async function scan(seed, x = 0, z = 0, radius = 100, max = 20, types = "5") {
    const url = new URL("/scan", BASE);
    url.searchParams.set("seed", String(seed));
    url.searchParams.set("x", String(x));
    url.searchParams.set("z", String(z));
    url.searchParams.set("radius", String(radius));
    url.searchParams.set("max", String(max));
    url.searchParams.set("types", types);  // IDs separados por vírgula, ex.: "5,8,9"

    const res = await fetch(url, { signal: AbortSignal.timeout(15000) });
    if (!res.ok) throw new Error(`HTTP ${res.status} ${res.statusText}`);
    return res.json();
}

(async () => {
    const data = await scan(31415, 0, 0, 100, 50, "5,8,9");
    for (const s of data.results ?? []) {
        console.log(`${s.name.padEnd(14)} (x=${s.x}, z=${s.z}) dist=${s.distance}`);
    }
})().catch((err) => {
    console.error("scan failed:", err);
    process.exit(1);
});
